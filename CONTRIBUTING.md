# Contributing to Ferret

Thanks for helping. Ferret is macOS-only (FSEvents, `getattrlistbulk`), so you need a Mac with Rust stable.

## Build and test

```sh
cargo build --workspace
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all
```

CI runs the same four commands on every push and pull request.

## Layout

| Crate | Builds | Job |
|---|---|---|
| `crates/ferret-core` | library | index, scanner, query parser, search, snapshot, socket protocol |
| `crates/ferret` | `ff`, `ferretd` | CLI, picker, shell integration, daemon with FSEvents |
| `crates/ferret-mcp` | library | the MCP server behind `ff mcp`, with its allow/deny policy |
| `crates/ferret-app` | `ferret` | the menu bar app (egui) |

Only `ferretd` touches the disk and holds the live index; every front end talks to it over the newline-delimited JSON protocol in `ferret-core/src/protocol.rs`, and falls back to the snapshot when it isn't running.

## Running locally

```sh
cargo run --release -p ferret --bin ff -- index --stats   # first scan
cargo run --release -p ferret --bin ferretd               # daemon in the foreground
cargo run --release -p ferret --bin ff -- invoice *.pdf
cargo run --release -p ferret-app                         # menu bar app
```

## Pull requests

- Keep changes focused, and add a test for new logic or a fixed bug.
- Changes to `ferret-mcp`'s policy (allow/deny, path checks) need a test that proves a denied path stays denied.
- Bump the snapshot `VERSION` in `ferret-core/src/snapshot.rs` if you change the layout of `Index` or `Node`.

## Releases

Tag `vX.Y.Z` on `main`. `release.yml` (generated by [cargo-dist](https://opensource.axo.dev/cargo-dist/); edit `dist-workspace.toml` and run `dist generate` instead of editing it by hand) builds the binaries, the Homebrew formula and the menu bar app `.dmg`.
